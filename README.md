# Programming Task

This Workspace will contain tasks that are given and presonal projects.

## Projects

- [Brute force demo](brute%20force/README.md) - searches for a 4-digit PIN and reports the attempt count and runtime.
- [Login demo](login/README.md) - simulates a login system with limited attempts and a temporary lockout.

## Folder Layout

```text
programming task/
├── brute force/
│   ├── Brute_force.py
│   └── README.md
└── login/
    ├── login.py
    └── README.md
```

## Running the Scripts

Use Python 3 to run either script from its folder:

```bash
python3 brute force/Brute_force.py
python3 login/login.py
```

Each subfolder also has its own README with more details.
